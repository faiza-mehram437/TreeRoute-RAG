# Screenshots

Add these four images (PNG, about 1400 px wide). The main README already links to them:

| File | What to capture |
|---|---|
| `chat.png` | The Chat tab after asking a question, with the answer, its `[1]` citations and the Sources box open |
| `equipment.png` | The Equipment tab for the drone paper, showing the cards and store buttons |
| `related.png` | The Related papers tab with the tree graph |
| `figures.png` | The Figures tab |

On Windows, press `Win + Shift + S` to capture part of the screen, then paste into Paint and save as PNG.
